THƯ MỤC CHỨA NHẠC NỀN DỰ ÁN (BGM)
=====================================
Bạn có thể copy bất kỳ file nhạc nào (.mp3, .wav, .ogg) vào thư mục này.
Ví dụ:
1. Copy file nhạc và đổi tên thành: bgm.mp3
   Đường dẫn: /public/music/bgm.mp3

2. Trò chơi có thể phát trực tiếp bài hát này bằng cách chọn "Phát file /music/bgm.mp3" trong menu Nhạc nền!

Ngoài ra, bạn cũng có thể chọn file nhạc trực tiếp từ máy tính trên giao diện mà không cần copy file vào đây!
